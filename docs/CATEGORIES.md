# Partner categories

As read on the challenge hub on Oct 13 2026. **Re-read the hub before you claim anything.** You can enter every category you genuinely use but win only once per challenge. Partner categories come from smaller pools. Do not bolt on a technology just to enter.

| Category | What the hub asked for | What to do here | Evidence for the post |
|---|---|---|---|
| Gemma (featured) | use Gemma: run locally, fine-tune, or serve it elsewhere | already core: `gemma4:e4b` through Ollama for vision + drafting. Compare e2b vs e4b | the eval tables, timings on your laptop, the Apache-2.0 note |
| .tech domain | project live on a .tech domain claimed through Hacktoberfest (free first year at hacktoberfest.com/my/promos) | claim the domain, host the landing page and the recorded replay (never pretend the hosted page runs the model) | the live URL, a screenshot of the domain in your account |
| Entire | share the agent sessions behind the project | only if you use their tool while building | embedded or linked session(s) in the post |
| GitHub Copilot | Copilot coding agent/CLI/app, or automate with GitHub Actions | CI already runs lint, tests and the fault-injection eval on every push; use Copilot only if you really do | the Actions run, PRs or sessions |
| Sentry agent tracing | show the agent's work: setup, latency, tokens, cost, how you debugged | optional; must be opt-in and metadata-only because the product promise is that nothing leaves the laptop | traces or screenshots, setup description |
| Tinker | fine-tune a model for a task and show improvement over a baseline | only if you really fine-tune; not part of this build | baseline vs tuned numbers |
| Render / DigitalOcean | hosting | only for the landing/replay page if it truly runs there | deploy link |

The rest of the partner list is not a fit for an offline tool. Do not stretch.
